# RestroPulse SVG icon catalog

The application icons in this directory come from the free Hugeicons
stroke-rounded collection and use its consistent 24 × 24 grid and 1.5px
rounded strokes. They are rendered directly with `SvgPicture.asset`.

- Source: https://github.com/hugeicons/hugeicons-static
- Author: Hugeicons
- License: MIT/free icon collection; see the upstream repository for terms.

Files are kept locally so every icon remains centralized under `assets/svg/`.
The catalog intentionally reuses one semantic icon across related screens and
navigation; active navigation state is communicated by color instead of a
duplicate SVG variant.
